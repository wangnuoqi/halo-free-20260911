# Papers and Analysis

## Files

- `NAFNet_2204.04676.pdf`: downloaded arXiv version of *Simple Baselines for
  Image Restoration* (NAFNet), arXiv:2204.04676.
- `Visual-in-Visual_ A Unified and Efficient Baseline for Image Restoration.pdf`:
  local VIVNet paper, verified as a valid 19-page PDF.
- `VIVNet_TPAMI_2026.metadata.json`: DOI, IEEE record, official repository,
  local PDF path, and source metadata for VIVNet.
- `IMPROVEMENT_PLAN_CN.md`: analysis of the current gap and the proposed
  experiment sequence.
- `ablation_matrix.yaml`: fixed A/B/R experiment IDs, metrics, and fairness
  constraints for the next runs.

The local VIVNet PDF is now available for paper-level verification. The official
implementation is already available in `../baseline/vivnet_wls/` and the
original RGB repository is preserved in
`../../20261005_clipart_removal/baselines/VIVNet/`.
